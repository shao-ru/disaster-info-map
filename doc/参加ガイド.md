# 避難所・防災マップ プロジェクト 参加ガイド

## 1. このプロジェクトについて

大雨・洪水などの災害が起きたときに、スマートフォンで

- 自分のいる場所の危険度（想定される浸水の深さなど）
- 近くの避難所と、そこまでの道すじ
- 雨や川の様子、過去の災害の記録

を調べられるアプリ（Web アプリ）をつくります。ふだんネットにつながっているときに地域のデータをダウンロードしておき、**災害でネットがつながらなくても使える**ことを目指します。

データは全国分を使います。まずは**柏市とその周辺**を重点的に分析し、その後ほかの地域に広げていきます。

完成したアプリは公開し、だれでも試せるようにします。自分が担当した部分は、就職活動などで「自分の成果」として説明できます。

---

## 2. 全体の仕組み

```
① 地域を決める
   GPS の位置＋半径、または都道府県・市区町村を指定
        ↓
② データ処理（Python）
   地域に合わせて、データを集める・切り出す・整える・分析する
        ↓
③ 決められた形式のデータ（GeoJSON、CSV、JSON など）
        ↓
④ 可視化（Web アプリ）
   ③ のデータを読み込み、地図や一覧、グラフで表示する
```

- **②データ処理** と **④可視化** は分かれています。③のデータ形式さえ守れば、それぞれ別々に作業を進められます。
- 地域を変えるときは、①の指定を変えて②をもう一度実行するだけです。

## 3. 参加のしかた

### 3.1 使うもの

- **GitHub**：コードとデータの置き場所。作業の依頼（Issue）や変更の提案（Pull Request）もここで行います。
- **ブラウザー**：アプリの確認、GitHub 上での簡単な編集。
- **自分の PC**（課題によって）：Python（uv）でデータ処理を動かす、アプリを手元で動かす。

### 3.2 作業の流れ

1. GitHub の **Issue** で、取り組む内容を選ぶ（自分の名前を担当者にする）
2. 作業する（簡単な修正なら GitHub のページ上で直接編集できます）
3. **Pull Request（PR）** を作る：「何を変えたか」「どう確かめたか」を書く
4. 先生が確認し、OK なら取り込まれる（マージ）
5. 公開中のアプリに反映され、自分のスマホで確認できる

### 3.3 約束ごと

- **1 つの Issue は 1 週間以内に終わる大きさ**にします。大きすぎると感じたら分けてもらいましょう。
- **1 日以上つまずいたら、Issue にコメントして質問**してください。質問するのも大事な貢献です。
- **完成の基準**：動く／スマホでも確かめた／PR に「何を変えたか・どう確かめたか」を書いた。
- **AI（ChatGPT、Copilot など）は使ってよい**です。ただし、PR の中のコードはすべて自分で説明できること。AI に手伝ってもらった部分は PR に書いてください。
- 写真やデータには、**出典と撮影日**を必ず残します。人の顔や車のナンバーは写さないようにします。

## 5. 最初にやること（全員）

### 5.1 プロジェクトの基本設定　★☆☆☆☆

- [ ] GitHub のアカウントを作り、先生に伝える（プロジェクトに招待されます）
- [ ] GitHub Desktop をインストールし、プロジェクトを自分の PC にコピー（clone）する
- [ ] uv（Python の実行環境）をインストールする
- [ ] プロジェクトのフォルダーで次を実行し、http://localhost:8000/web/ でアプリが表示されることを確認する
  ```
  uv run ./code/serve.py
  ```
- [ ] このプロジェクトで使う Git のユーザー名とメールアドレスを設定する（匿名）
  公開リポジトリでは、コミットに書いたユーザー名とメールアドレスが誰でも見られます。本名や個人のメールアドレスを出さないように、GitHub が用意している匿名のアドレスを使います。
  1. GitHub の Settings → Emails を開き、「Keep my email addresses private」にチェックを入れる
  2. 同じ画面に表示される `数字+ユーザー名@users.noreply.github.com` という形のアドレスをコピーする
  3. プロジェクトのフォルダーで次を実行する（`--global` を付けないので、このプロジェクトだけの設定になります）
  ```
  git config user.name "GitHubのユーザー名"
  git config user.email "12345678+ユーザー名@users.noreply.github.com"
  ```
  4. 次のコマンドで、設定できたか確認する
  ```
  git config user.name
  git config user.email
  ```
  GitHub Desktop を使う場合も、この設定がそのまま使われます。
- [ ] [`CONTRIBUTORS.md`](../CONTRIBUTORS.md)（プロジェクトの一番上のフォルダー）に自分の名前を追加して、最初の Pull Request を出す

うまくいかなかったところは、何をしたら、どんなメッセージが出たかを Issue に書いてください。次の人の役に立ちます。

### 5.3 自分の周辺の避難所 3 か所の写真　★☆☆☆☆

自宅や大学の近くの避難所を 3 か所選び、次を記録します。

| 項目 | 内容 |
|---|---|
| 避難所の名前 | アプリに表示される名前 |
| 避難所 ID | アプリの避難所データの id（先生が調べ方を説明します） |
| 撮影日 | |
| 写真 1 | 入口（どこから入るかがわかるように） |

注意：敷地の外から撮影する／人の顔や車のナンバーを写さない／暗い時間や雨の日は無理をしない。
