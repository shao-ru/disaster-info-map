# 避難所マップのしくみ（課題に取り組む前に読む）

このアプリが、どんなデータを使い、ボタンを押したときに何が起きているのかを説明します。
課題 1〜3 は、この流れの一部を自分で書く課題です。

```
【データの準備】Python（済み）                     【アプリ】JavaScript（ブラウザーで動く）
国土地理院の避難所 ─┐                              ① 画面で選ぶ
e-Stat の境界 ──────┼→ data/static/ ─────────→    ② 〜 ⑤ 範囲を決めて避難所を探す
                    ┘   （アプリ用のデータ）        ⑥ 地図と一覧に表示
```

## 1. データの準備（前処理）で行ったこと

元のデータは大きく、形もアプリでそのまま使いにくいので、Python で整理して `data/static/` に置いてあります。
アプリはここにあるファイルだけを読み込みます。

### 1.1 避難所

| | |
|---|---|
| 元データ | 国土地理院「指定緊急避難場所・指定避難所データ」（全国） |
| みんなで直すファイル | `data/static/shelters/mergeFromCity_1_refine.csv`（指定避難所、約 8.3 万行）<br>`data/static/shelters/mergeFromCity_2_refine.csv`（指定緊急避難場所、約 11.6 万行） |
| 変換ツール | `code/build_shelters.py` |
| できるファイル | `data/static/shelters/<県コード>.geojson`（47 ファイル。例：`12.geojson` ＝ 千葉県） |

`build_shelters.py` がしていること：

1. **2 つの CSV を読み、間違いがないか調べる**
   共通 ID の重複、緯度・経度が数値か・日本の中か、など。間違いがあれば行番号を表示して止まる
2. **同じ施設を 1 つにまとめる**
   「指定避難所」と「指定緊急避難場所」の両方に指定されている施設は、2 つのファイルに 1 行ずつある。
   共通 ID の先頭 11 文字と施設名が同じものを、同じ施設としてまとめる（全国で約 15.4 万施設）
3. **アプリで使いやすい形にする**
   緊急避難場所の「洪水」「地震」などの列（1 か空）を、`hazards: ["flood", "quake", …]` という一覧に変え、
   洪水に対応するかどうかを `flood: true / false` にまとめる
4. **都道府県ごとのファイルに分ける**
   全国を 1 つにすると大きすぎる（スマホで重い）ため。必要な県のファイルだけを読み込めばよい

できた GeoJSON の避難所 1 件は、次の形です。

```json
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [139.990436, 35.857532] },
  "properties": {
    "id": "E1221700021111", "ids": ["E1221700021111", "E1221700021201"],
    "name": "日本体育大学柏高等学校", "address": "千葉県柏市戸張944",
    "prefCode": "12", "cityCode": "12217", "pref": "千葉県", "city": "柏市",
    "shelter": true, "emergency": true,
    "hazards": ["flood", "inland", "landslide", "quake", "fire"], "flood": true,
    "target": "", "note": ""
  }
}
```

`coordinates` は **[経度, 緯度]** の順です（緯度・経度ではありません。よく間違えるところです）。

### 1.2 市区町村の境界

| | |
|---|---|
| 元データ | e-Stat「2020 年国勢調査 小地域（町丁・字等）境界データ」（全国） |
| 変換ツール | `code/build_boundaries.py` |
| できるファイル | `data/static/admin_boundaries/<県コード>.geojson`（市区町村ごとの多角形） |

1. 町丁・字（「柏市明原一丁目」などの小さな区域。千葉県だけで約 6,700）を、**市区町村ごとに 1 つの多角形にまとめる**（融合、dissolve）
2. 政令市の区（例：千葉市中央区）は、避難所データに合わせて **市全体（千葉市）にまとめる**
3. 細かすぎる形を **約 30 m の精度に簡略化** して、ファイルを小さくする

### 1.3 都道府県・市区町村の一覧（regions.json）

`data/static/regions.json` には、画面の選択肢に使う一覧が入っています。

```json
{
  "prefectures": [ { "code": "01", "name": "北海道" }, … ],
  "cities": [
    { "code": "12217", "prefCode": "12", "pref": "千葉県", "name": "柏市", "fullName": "千葉県柏市",
      "center": [139.98848, 35.85901],
      "bbox": [139.9132, 35.78099, 140.11195, 35.93631],
      "count": 146 },
    …
  ]
}
```

- `center`：市区町村の中心（一覧の「○○の中心から近い順」の基準）
- `bbox`：市区町村を囲む四角形 [最小経度, 最小緯度, 最大経度, 最大緯度]（課題 2 で使う）
- `count`：その市区町村の避難所の数

ブラウザーで http://localhost:8000/data/static/regions.json を開くと、中身を見られます。

## 2. 「表示」ボタンを押したときの流れ

画面で「千葉県 / 柏市 / ＋周辺 5 km」を選んで **「表示」** を押すと、`web/js/main.js` の `runCity()` と `search()` が、次の順に関数を呼びます。

| | すること | ファイル | 関数 | 受け取るもの → 返すもの |
|---|---|---|---|---|
| ① | 選ばれた県・市・距離を読む | `main.js` | `runCity()` | 画面の選択 → `"千葉県"`, `"柏市"`, `5` |
| ② | **市区町村の情報を探す** | `student/region.js` | **`getRegion()`　課題 1** | 県名・市名・regions → 柏市の情報（`code`, `center`, `bbox` …） |
| ③-1 | 市区町村の境界を読み込む | `data.js` | `loadBoundary()` | 柏市の情報 → 柏市の多角形 |
| ③-2 | 境界を 5 km 広げて「範囲」を作る | `geo.js` | `bufferArea()` | 多角形, 5 → 広げた多角形（範囲） |
| ④ | **範囲にかかる都道府県を調べる** | `student/search.js` | **`findPrefectures()`　課題 2** | 範囲・regions → `["12", "08", "11", "13"]` |
| ⑤-1 | その都道府県の避難所を読み込む | `data.js` | `loadShelters()` | `["12", "08", …]` → 4 都県の避難所すべて |
| ⑤-2 | **範囲の中の避難所だけを選ぶ** | `student/search.js` | **`filterInArea()`　課題 3** | 避難所すべて・範囲 → 範囲の中の避難所 |
| ⑥ | 地図と一覧に表示する | `main.js` | `showResult()` | 範囲・境界・避難所 → 画面（地図の点、紫の範囲、件数、近い順の一覧） |

「現在地から ○ km」の **「探す」** を押したときは、①〜③ が「現在地を中心にした円を作る」（`geo.js` の `circleArea()`）に変わるだけで、④〜⑥ は同じです。

④ で都道府県を調べるのは、避難所のファイルが都道府県ごとに分かれているからです。
柏市の周辺 5 km は、千葉県だけでなく茨城県・埼玉県・東京都にもかかります。

## 3. 今の状態：課題の関数は「仮の実装」

課題 1〜3 の関数は、今は次のように「とりあえず動く」だけの中身になっています。

| 課題 | 関数 | 今の中身（仮の実装） | その結果、画面では |
|---|---|---|---|
| 1 ★ | `getRegion()` | 何を選んでも **柏市** を返す | どの市を選んでも柏市が表示される |
| 2 ★★ | `findPrefectures()` | どこでも **千葉県（"12"）だけ** を返す | 県境の向こう（茨城・埼玉・東京など）の避難所が出ない |
| 3 ★★ | `filterInArea()` | **何も選ばず全部** 返す | 範囲の外も含め、千葉県の避難所が全部表示される |

流れ全体（①〜⑥）は完成しているので、この 3 つの関数を正しく書けば、選んだ場所の結果が正しく表示されます。

どこが未完成かを確かめる方法：

- 画面の左の欄の下にある **「課題チェック」**（`web/test.html`）を開く → 課題ごとに ✅ / ❌ とヒントが出る
- ブラウザーで **F12** を押し、**Console** を見る → `[課題チェック]` で始まるメッセージが出る

## 4. 進め方

### ステップ 1：まず読んで、慣れる（20〜30 分）

1. アプリを起動して、いろいろ操作してみる（起動方法は [参加ガイド](参加ガイド.md) の 5.1）
2. 次のファイルを、この順に読む（全部わからなくてよい。流れをつかむ）
   1. `web/js/student/region.js` … 課題 1。上のコメントに説明とヒントがある
   2. `web/js/student/search.js` … 課題 2・3
   3. `web/js/geo.js` … 課題で使える部品（`bboxOf`、`bboxesOverlap`、`isInside`）
   4. `web/js/main.js` の `runCity()` と `search()` … 上の表の ①〜⑥ がどこにあるか探す
3. データの中身をブラウザーで見る
   - http://localhost:8000/data/static/regions.json
   - http://localhost:8000/data/static/shelters/12.geojson（千葉県。少し大きい）

### ステップ 2：課題 1 → 2 → 3 の順に書く

1. 関数の中の「仮の実装」の行を書き換える
2. ファイルを保存して、`test.html` を再読み込みする → ✅ になるまで直す
3. アプリ（`index.html`）でも、いろいろな市や距離で試す
4. できたら Pull Request を出す

困ったとき：

- 関数の中に `console.log(変数)` を書くと、F12 の Console に中身が表示される
- 1 つの課題で 15 分以上止まったら、Issue に「どこまでできて、何が出たか」を書いて相談する
