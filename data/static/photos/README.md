# data/static/photos（避難所の写真）

アプリで避難所をクリックし、「写真を追加」から登録すると、ここに保存されます（手元で `uv run ./code/serve.py` を動かしているときだけ使えます）。

- `<施設のID>_<GitHubユーザー名>_<番号>.jpg` … 写真（自動で小さくし、位置情報を消してあります）
- `<施設のID>_<GitHubユーザー名>_<番号>.json` … 説明（撮影日・撮影者・メモ）
- `index.json` … 写真の一覧。自動で作られるので、Git には入れません

チェック：`uv run ./code/build_photos.py`

くわしくは [doc/避難所の調査と写真.md](../../../doc/避難所の調査と写真.md) を見てください。
